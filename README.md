## 自动发布流程

`blog-src (Private)` → `GitHub Actions 构建 / 可选 AES 加密` → `wayfare11.github.io (Public)` → `GitHub Pages`。

本仓库由自动部署流程维护，请**不要直接修改**生成文件；下一次发布会覆盖这些修改。完整配置、操作文档、构建说明和安全注意事项维护在私有源码仓库的 `README.md` 和 `site/README.md` 中，需获得访问权限才能查看。
